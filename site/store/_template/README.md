# 加盟店 店舗ページ テンプレート（/store/_template/）

新しい加盟店の公開ページを追加するときの雛形です。

## 新規店舗の追加手順

1. このフォルダ `store/_template/` を丸ごとコピーして、`store/<slug>/` にリネームします。
   - `<slug>` は英数字・ハイフンのみ（例：`sendai`, `koriyama`, `mito`）。
   - これが公開URL `https://buymo.me/store/<slug>/` になります。
2. コピーした `store/<slug>/index.html` の `<meta name="robots" content="noindex,nofollow" />` を **削除**します（テンプレートは検索避けのため付いています。公開店舗は消してOK）。
3. 加盟店アカウントの `store` 値を、この `<slug>` に合わせて設定します（ログイン後「マイ店舗ページ」の編集内容がこのページに反映されます）。
4. `store/index.html`（加盟店一覧）に、この店舗のカードを追加します。

## 反映の仕組み

- ページ末尾の `store-page.js` が **URLからスラッグを自動判定**し、GASから店舗内容を取得して反映します。
  - 店舗名・所在地（地図）・キャッチ・紹介文・対応エリア・電話/LINE/メール・SNS・買取実績・ブログ
- 手作業でHTMLを書き換える必要はありません。すべて加盟店が「マイ店舗ページ」から編集できます。
- GAS未反映の間は、テンプレートの初期表示（○○店などのプレースホルダ）が出ます。

## 注意

- 共通スクリプトは `assets/js/store-page.js` の1ファイルです。全店舗ページが同じものを読み込むため、
  ロジック修正は1箇所でOKです（各ページの編集は不要）。
