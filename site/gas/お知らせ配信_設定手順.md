# 本部→加盟店 お知らせ配信 設定手順

本部「お知らせ管理」で登録したお知らせを、**全加盟店の画面に共有表示**する機能です。
データは GAS の Google スプレッドシート（シート名「お知らせ」）に保存されます。

## 仕組み
- 本部：`hq-notices.html`（お知らせ管理）で登録・削除 → GAS に保存
- 加盟店：ポータル上部のバナー／ダッシュボードに、本部が登録したお知らせを表示
- 保存先：スプレッドシートのシート「お知らせ」（列：ID / 日時 / レベル / タイトル / 本文）※初回登録時に自動作成

## ⚠️ 反映手順（GAS 側の更新が必須）
リポジトリの `buymo-backend-v7.gs` は写しです。実際に動く GAS を更新してください。

1. https://script.google.com/ で BUYMO のスクリプトを開く
2. `buymo-backend-v7.gs` を、このリポジトリの最新版で**上書き保存**
   - 追加点：`doGet` に `action=notices`、`doPost` に `type=notice` / `type=notice_delete`、および
     `getNoticesData` / `saveNotice` / `deleteNoticeData` / `getNoticeSheet` 関数、`NOTICE_SHEET_NAME`
3. 「デプロイ」→「デプロイを管理」→ 対象ウェブアプリ ✏️ →「バージョン＝新バージョン」→ デプロイ
   - ウェブアプリ URL は変わりません（サイト側の設定変更は不要）
4. 本部 `hq-notices.html` でお知らせを登録 → 別ブラウザ（加盟店）で表示されれば成功

## 補足
- GAS を更新するまでは、従来どおり各端末内の既定お知らせ（サンプル4件）が表示されます（フォールバック）。
- GAS 更新後は、本部が登録したお知らせが全員に共有表示されます。
