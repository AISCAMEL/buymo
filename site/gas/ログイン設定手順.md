# 本部/加盟店ログイン 設定手順

本部・加盟店の業務ログインは **メールアドレスの許可リスト方式**（パスワード不要）です。
判定は画面側（`assets/js/auth.js`）で行うため、**GAS の設定・再デプロイは不要**です。

## 仕組み
- ログイン画面（`portal-login.html`）でメールアドレスを入力 →「本部でログイン」/「加盟店でログイン」。
- `auth.js` の許可リストに載っていれば入れます（パスワードは使いません）。
- 本部(hq)＝全権限／加盟店(partner)＝加盟店ページのみ。本部は加盟店ページも閲覧可。

## 誰がログインできるか（許可メール）
`site/assets/js/auth.js` の先頭付近を編集します。

```js
var STAFF_HQ = ['info@aisjaltd.com', 'kaitori@buymo.me', 'test@buymo.me']; // 本部
var STAFF_PARTNER = []; // 加盟店（例: 'store-iwaki@example.com'）
```

- **本部スタッフを追加**：`STAFF_HQ` にメールを追記
- **加盟店スタッフを追加**：`STAFF_PARTNER` にメールを追記（`[]` の中にカンマ区切りで）
- 追記して保存 → サイトを反映（mainにマージで自動デプロイ）するだけ

## 反映手順
1. `STAFF_HQ` / `STAFF_PARTNER` を編集（必要な場合）
2. `main` にマージ → buymo.me へ自動デプロイ
3. `portal-login.html` で `info@aisjaltd.com` を入力し「本部でログイン」→ 入れれば成功
   - キャッシュで古い場合はスーパーリロード（Ctrl+F5 / ⌘+Shift+R）

## 補足（セキュリティ）
- これは画面側（クライアント）のログインゲート＋メール許可リストによる簡易認証です。
  ソースを見ればメール一覧は分かるため、機密性の高い運用が必要になったら
  サーバー側（GAS等）での本格的なパスワード認証を別途設計します。
- 会員（お客様）マイページは別方式（登録済みメールで査定状況を確認）。
