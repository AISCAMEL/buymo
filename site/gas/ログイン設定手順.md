# 本部/加盟店ログイン 設定手順（重要）

本部・加盟店の業務ログインは **メールアドレスの許可リスト方式**（パスワード不要）です。
ログインできるのは「許可リストに登録されたメールアドレス」だけです。

## 仕組み
- ログイン画面（`portal-login.html`）でメールアドレスを入力 →「本部でログイン」/「加盟店でログイン」。
- `auth.js` が GAS（`?action=login`）に問い合わせ、GAS の `staffLogin()` が許可リストで判定。
- 本部(hq)＝全権限／加盟店(partner)＝加盟店ページのみ。パスワードは使いません。

## 許可リスト（誰がログインできるか）
既定で **本部** として常に許可：
- `info@aisjaltd.com`
- `kaitori@buymo.me`
- `test@buymo.me`

追加・変更は GAS の **Script Properties** で行います（コード修正不要）：
| プロパティ名 | 値（カンマ区切り） | 役割 |
|---|---|---|
| `HQ_EMAILS` | 本部スタッフのメール | 本部（全権限） |
| `PARTNER_EMAILS` | 加盟店スタッフのメール | 加盟店 |

## ⚠️ 反映手順（これをやらないと動きません）
リポジトリの `buymo-backend-v7.gs` は**コードのコピー**です。実際に動くのは
Google Apps Script 上の Web アプリなので、**GAS側の更新と再デプロイが必須**です。

1. https://script.google.com/ で BUYMO のスクリプトプロジェクトを開く
2. `buymo-backend-v7.gs` の内容を、このリポジトリの最新版で**上書き**して保存
3. （必要なら）「プロジェクトの設定」→ Script Properties に `HQ_EMAILS` / `PARTNER_EMAILS` を追加
4. 「デプロイ」→「デプロイを管理」→ 対象のウェブアプリの ✏️ →「バージョン＝新バージョン」→ デプロイ
   - ※ ウェブアプリ URL は変わりません（`auth.js` の `ENDPOINT` はそのままでOK）
5. `portal-login.html` で `info@aisjaltd.com` を入力し「本部でログイン」→ 入れれば成功

## 補足（セキュリティ）
- このログインは画面側（クライアント）のゲート＋メール許可リストによる簡易認証です。
- 本格的なパスワード認証やサーバーセッションが必要になった場合は別途設計します。
