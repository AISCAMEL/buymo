# ジャンル別ヒーロー背景画像

このフォルダに画像を入れると、対応するジャンルページのヒーロー（上部）に
自動で背景写真が表示されます。画像が無い場合は従来のグリーン背景のままなので、
1枚ずつ差し替えても崩れません。

## 仕様
- サイズ: 1920 × 820px（21:9 目安）
- 形式: JPG
- ファイル名: 下記スラッグ名 + `.jpg`（例: `hiace.jpg`）
- 構図: 左側に文字が乗るため、被写体は右寄り・左は余白を意識
