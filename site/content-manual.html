コンテンツマニュアルカーメル 制作チーム用

BUYMOサイトのコラム記事・エリアLP・ジャンルLP・お知らせ・アカデミー資料・販促物を、誰が作っても同じ品質になるようにまとめた制作・入稿マニュアルです。書き方（トンマナ・NG表現）、SEOルール、入稿画面の使い方、公開の反映のしくみ、公開前チェックまでを1ページに集約しています。

🗺️ コンテンツ全体像（何を・どこで作るか）

BUYMOのコンテンツは「管理画面から入れるもの（即時反映）」と「リポジトリのHTMLを編集するもの（デプロイで反映）」の2系統があります。まずここで自分の担当がどちらかを確認してください。

コンテンツ作る場所公開先反映
コラム記事 コラム投稿 /column/ 即時
お知らせ お知らせ管理 本部・加盟店の各画面 即時
アカデミー教材・PDF資料 アカデミー管理 加盟店アカデミー 即時
エリアLP（47都道府県） tools/gen-area.js ＋ データ編集 /area/ 生成＋デプロイ
ジャンルLP assets/js/genres.js ＋ tools/gen-genre.js /genre/ 生成＋デプロイ
外部LP原稿（LPtools） embed/LP原稿_*.md LPtools側のLP 転記時
販促物・トークスクリプト 販促ツール／スクリプト 加盟店ポータル デプロイ
迷ったらコラムから。コラムは管理画面だけで完結し、公開ボタンで /column/ に即時反映されます。エンジニア対応は不要です。

投稿後は必ず /column/ を開いて実ページの表示崩れ・改行・リンクを確認してください。修正は「📋 投稿一覧」から行います。

📄 記事テンプレート（コピーして使う）

本文欄にそのまま貼って、［　］の中を差し替えるだけで1本書けます。型は3種類。

① 悩み解決型（例：ローン中の車を売りたい）
<p>［読者の悩みを1文で言い換える］とお困りではありませんか。結論から言うと［結論］です。この記事では［得られること］を、買取の現場目線で解説します。</p>

<h2>［悩み］が起きる理由</h2>
<p>［背景・仕組みを2〜3文］</p>

<h2>結論：［いちばん伝えたい答え］</h2>
<ul>
  <li>［ポイント1］</li>
  <li>［ポイント2］</li>
  <li>［ポイント3］</li>
</ul>

<h2>手順（やることリスト）</h2>
<p>［1. …／2. …／3. … を短文で］</p>

<h2>注意点・よくある失敗</h2>
<p>［トラブル例と回避策］</p>

<h2>よくある質問</h2>
<p><strong>Q. ［質問］</strong><br>A. ［回答］</p>

<h2>まとめ</h2>
<p>［要点の再確認］。BUYMOでは無料査定を受け付けています。査定・出張・手続き代行はすべて無料です。まずはお気軽にご相談ください。</p>
② 車種・ジャンル型（例：ハイエースの買取相場）
<p>［車種／ジャンル］は［人気の理由］から、中古市場で需要が安定しています。ここでは［車種］を売るときに押さえたいポイントをまとめます。</p>

<h2>［車種］が高く評価される理由</h2>
<p>［需要・流通の背景］</p>

<h2>査定でチェックされるポイント</h2>
<ul>
  <li>年式・走行距離：［目安］</li>
  <li>グレード・装備：［人気装備］</li>
  <li>状態：［傷・修復歴の扱い］</li>
</ul>

<h2>高く売るためのコツ</h2>
<p>［清掃・書類・売却時期など］</p>

<h2>こんな状態でも買取できます</h2>
<p>事故車・不動車・過走行・ローン中の車もご相談いただけます。</p>

<h2>まとめ</h2>
<p>［要点］。実際の金額は車両ごとに異なるため、無料査定でご確認ください。</p>
③ 手続き解説型（例：廃車の必要書類）
<p>［手続き名］は、必要書類さえそろえば難しくありません。この記事では［手続き名］の流れと必要書類を、はじめての方向けに整理します。</p>

<h2>［手続き名］とは</h2>
<p>［定義を1〜2文］</p>

<h2>必要書類</h2>
<ul>
  <li>［書類1］：［どこで入手］</li>
  <li>［書類2］：［注意点］</li>
</ul>

<h2>手続きの流れ</h2>
<p>［STEP1〜4を短文で］</p>

<h2>つまずきやすいポイント</h2>
<p>［所有権解除・書類紛失など］</p>

<h2>まとめ</h2>
<p>BUYMOでは［手続き名］の代行に対応しています。書類の準備からご相談ください。</p>
テンプレの見出しは増減してOKですが、「結論を先に→理由→手順→注意点→まとめ」の順序は崩さないでください。読者は結論を探して読んでいます。

🗣️ 書き方・トンマナ

  • 文体は「です・ます」で統一敬体のみ
  • 一人称は「BUYMO」／署名は「BUYMO編集部」個人名は出さない
  • お客様のことは「お客様」（ユーザー・客はNG）呼称統一
  • 1文は60文字以内。長い文は2つに割るスマホで読める長さ
  • 2〜4文ごとに改段落、3スクロールに1つ見出し余白を作る
  • 専門用語は初出でかみ砕く（例：抹消登録＝車を使わなくする手続き）初心者基準
  • 数字は半角、金額は「¥」ではなく「〇〇万円」表記本文中の統一
  • 不安を煽らない。事実→対処法の順で書く誠実なトーン

用語の統一

使う買取／査定／無料出張査定／手数料0円／名義変更／廃車手続き／加盟店／お客様
使わない買い取り（送り仮名ゆれ）／見積り（記事では「査定」に統一）／ユーザー／弊社（→BUYMO）
BUYMOの訴求軸は「高価買取・手数料0円・無料出張査定・3営業日以内の入金・事故車/不動車/ローン中もOK」。どの記事でも最後にこの軸へ着地させます。

🚫 NG表現・法務チェック

必読
景品表示法上、断定・最上級・根拠のない保証は使えません。判断に迷う表現は公開前に本部へ確認してください。
区分NG例言い換え
最上級 業界No.1／日本一／どこよりも高い 高価買取に力を入れています
断定・保証 必ず〇〇円／最高額保証／絶対に損しません 車両により異なります。無料査定でご確認ください
誇大 他社より必ず10万円高い／今だけ限定 他社様の査定額もぜひ比較してください
実績の断定 買取実績（金額を実例として断定） 金額表の近くに「※ 掲載の実績は買取イメージです。」を必ず添える
相場の断定 2026年の相場は〇〇万円です 〇〇万円前後が目安です（時期・状態により変動します）
  • 他社名を挙げた比較・批判はしない比較は自社の事実のみ
  • 他サイトの文章・画像の転載はしない（引用は出典明記＋最小限）著作権
  • お客様の実名・車両ナンバー・書類画像を載せない個人情報
  • 古物営業法・許可番号の記載は本部管理の表記をそのまま使う改変禁止
  • 税・法制度の記述は最新の公的情報を確認してから書く年度で変わる

🔍 SEOルール

  • 1ページ1キーワード。同じキーワードで2本作らない共食い防止
  • タイトルは30〜32文字、キーワードを前半に検索結果で切れない
  • meta description は90〜120文字、キーワード＋ベネフィットクリック率
  • H1は1ページに1つだけ。以降はH2→H3の順で飛ばさない構造
  • 関連する記事・ジャンルLP・エリアLPへ内部リンクを2〜3本回遊と評価
  • 画像には必ず alt を入れる（装飾画像は空alt）アクセシビリティ
  • 公開URL（スラッグ）は英数字。日本語URLは使わない共有時に壊れない

HTMLページを触ったら自動チェックを回す

エリアLP・ジャンルLPなどリポジトリのHTMLを編集した場合は、site/ ディレクトリで次を実行します。

公開前の自動チェック（site/ で実行）
node tools/seo-check.js     # title/canonical/description/H1/OGP/JSON-LD/title重複
node tools/check-links.js   # 内部リンク・画像・アンカー(#id)の切れ確認
node tools/launch-check.js  # 公開前の総合チェック
seo-check.js の必須チェック対象は buymo.html／genre/**／area/** です（管理画面系は noindex のため対象外）。JSON-LD の構文チェックは全ページに走ります。

🏙️ エリアLP・ジャンルLP

生成スクリプト

エリアLP（47都道府県）とジャンルLPは手書きせず、データ＋ジェネレーターで生成します。1ページだけ手で直すと、次の生成で上書きされます。

エリアLPデータは tools/gen-area.js 内の都道府県データ。編集後に node tools/gen-area.js を site/ で実行 → area/<slug>/index.html とハブ・sitemap.xml が再生成されます
ジャンルLP一覧の元データは assets/js/genres.js。node tools/gen-genre.js で genre/ を再生成
公開/準備中の切替genres.js の各ジャンルに url:'/genre/haisha/'・status:'live' を設定すると、全ページのナビ・カード・フッターのリンクが一斉に有効化。未公開は status:'coming'
絶対URLで出すSITE_URL=https://buymo.me node tools/gen-area.js のように環境変数を付けると canonical / sitemap / robots が絶対URLになります
外部LP（LPtools）原稿は embed/LP原稿_*.md。ブロック構成のまま上から転記します。ヘッダー・フッターは embed/BUYMO_共通ヘッダーフッター_LPtools.html を貼れば本体と見た目が揃います
生成されたページを直接編集しないこと。直すのはデータかテンプレートで、必ず再生成してから公開します。

📢 お知らせ・アカデミー資料

管理画面で完結
お知らせお知らせ管理から配信。件名は20文字以内、本文は結論→対応期限→問い合わせ先の順。加盟店の各画面に即時表示されます
PDF資料・解説アカデミー管理の「📚 PDF資料・解説の登録」で、カテゴリ／タイトル／PDFのURL／解説を登録。加盟店アカデミーに一覧表示されます
PDFのURLGoogleドライブ等の共有リンク（リンクを知っている全員が閲覧可）を使用。社内限定のままだと加盟店側で開けません。公開範囲は登録前に必ず確認
解説文「この資料は何のためか」「いつ使うか」を2〜3文。ファイル名の説明で終わらせない
研修コースコースID（英数字）・タイトル・説明を登録し、レッスンにYouTube埋め込みURL（https://www.youtube.com/embed/XXXX）を設定
加盟店向け資料は限定公開が前提です。顧客に配る販促物と、加盟店限定の実務資料を混在させないでください。

✅ 公開前チェックリスト

共通

  • 誤字脱字・表記ゆれを確認した（買取／査定／お客様）
  • NG表現（No.1・必ず・保証・断定）が無い
  • 金額・実績に「※ イメージです」等の注記がある
  • 個人情報・他社名・転載素材が含まれていない
  • 連絡先・URL・電話番号が最新で正しい
  • スマホ表示で崩れていない（文字が詰まっていない）

コラム記事

  • タイトルにキーワードが入り、30〜32文字に収まっている
  • 重複タイトル警告が出ていない（出た場合は既存記事の更新を検討した）
  • 本文に <h1> を書いていない／見出しがH2→H3の順
  • 内部リンク2〜3本を入れた
  • 👁プレビューでタグ崩れ・改行を確認した
  • 公開後に /column/ の実ページを開いて確認した

HTMLページ（LP等）

  • node tools/seo-check.js がエラー0
  • node tools/check-links.js がエラー0
  • title・canonical・description・OGPが設定されている
  • 生成ページを手編集していない（データ側を直して再生成した）
  • ナビ・フッター・sitemap への導線を追加した
判断に迷ったら公開せず本部に確認。出してから直すより、出す前に聞くほうが早いです。
